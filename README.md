# Online Bookstore

Requirements and design documentation for an online marketplace where buyers purchase books, sellers manage listings and fulfilment, and administrators moderate the platform.

## Architecture

The architecture is a proposed logical design based on the repository specifications. This repository currently contains documentation rather than an implemented application.
